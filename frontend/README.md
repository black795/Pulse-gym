# Pulse Gym · Frontend

React 19 + Vite + Tailwind v4 + React Router. Instrucciones completas en el README principal (`../README.md`).

```bash
npm install
npm run dev        # http://localhost:5173  (reenvía /api al backend en :8000)
npm run build      # revisa tipos y genera la versión de producción en dist/
```

La guía visual original del prototipo está en `docs/guia-diseno-pulse-gym.md`.
